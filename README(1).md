# LegalEaseAI

## Project Title
LegalEaseAI – AI Powered Legal Document Generator

## Project Description
LegalEaseAI is an AI-based web application that helps users generate legal documents automatically using Google's Gemini AI model.

## Phase 1: Brainstorming & Ideation Phase
- Problem: Legal documents take time to create manually.
- Solution: AI-powered document generation.

## Phase 2: Requirement Analysis Phase
### Functional Requirements
- Generate legal documents
- User input form
- Download generated files

### Non-Functional Requirements
- Fast response
- Easy to use
- Reliable

## Phase 3: Project Design Phase
